TerraByte (टेराबाइट) — Technical Stack & Architecture Specification
National Land Acquisition & Management Platform • RFCTLARR Act 2013 Compliant
Document Version: 1.0 (Official Release) • Classification: Official Technical Architecture

This specification outlines every technology component utilized across the TerraByte platform, categorized into Frontend, Backend, and Database/Storage layers, detailing their operational roles in clear, accessible terminology.

1. Frontend Technology Stack Client-Side

Everything executed locally inside the citizen or officer's web browser (Google Chrome, Microsoft Edge, Firefox).

HTML5
Markup Language
💡 Simple Analogy: The skeleton & brickwork of the house.
Role in TerraByte: Provides the semantic structural foundation for the portal. Defines the layout of the JanParichay Single Sign-On card, the 4-step identity verification forms, the digital E-Agreement previewer, and the government masthead/footer.
CSS3 & GIGW Tokens
Styling & UX
💡 Simple Analogy: The interior paint, styling & design.
Role in TerraByte: Implements the official Guidelines for Indian Government Websites (GIGW 3.0) visual design. Powers the 210px circular camera viewport (using clip-path: circle() and border-radius: 50%) to ensure the live camera and captured photo stay perfectly inside a circular screen.
Vanilla JavaScript (ES6+)
Application Logic
💡 Simple Analogy: The brain & nervous system.
Role in TerraByte: Drives the entire Single Page Application (SPA) without external frameworks. Validates PAN formats, calculates RFCTLARR compensation multipliers, controls the camera verification workflow, and executes instant role switching.
WebRTC MediaDevices API
Hardware Interface
💡 Simple Analogy: The direct cable to your webcam.
Role in TerraByte: Interacts directly with the device's physical hardware camera via navigator.mediaDevices.getUserMedia. Handles camera permissions, dual-camera switching (Flip Camera), and streams live video directly into the circular screen.
HTML5 Canvas API
Graphics & Shutter
💡 Simple Analogy: The digital camera shutter & trimmer.
Role in TerraByte: Captures an instantaneous snapshot from the live video stream, crops an exact 1:1 square centered on the face to avoid distortion, mirrors front-camera selfies, and exports high-quality JPEG image payloads.
SVG Vector Graphics
High-DPI Graphics
💡 Simple Analogy: Mathematical drawings that never blur.
Role in TerraByte: Renders the official Ashoka Lion Capital (*सत्यमेव जयते*), Digital India, and PM GatiShakti badges in razor-sharp detail across all screen resolutions and zoom levels.
Leaflet.js (v1.9.4)
GIS Land Mapping
💡 Simple Analogy: A custom digital satellite atlas.
Role in TerraByte: Renders 100 georeferenced cadastral land parcel polygons across the Bhopal, Raisen, and Sehore revenue divisions with acquisition boundary highlights, coordinates, and khatauni information.
Chart.js (v4.4.4)
Data Analytics
💡 Simple Analogy: An automatic graph & chart maker.
Role in TerraByte: Visualizes compensation disbursement statistics, Direct Benefit Transfer (DBT) progress, and acquisition status distribution on senior administrative dashboards.

2. Backend Technology Stack Server-Side

The server engine running on the host machine to handle network requests, file saving, and privacy safeguards.

PowerShell HTTP Daemon
Web & API Server
💡 Simple Analogy: The office receptionist & file clerk.
Role in TerraByte: Built on Microsoft .NET's System.Net.HttpListener. Listens on port 8080 to serve all web assets and handle API requests natively without requiring Node.js, Python, or Apache installations.
REST API Architecture
Web Services
💡 Simple Analogy: The standardized ordering window.
Role in TerraByte: Exposes structured endpoints such as POST /api/idv/upload-photo and GET /api/idv/verifications for transmitting identity photographs and retrieving verification records.
Vault Access Guard
Security & DPDP
💡 Simple Analogy: The security guard with a lock.
Role in TerraByte: Protects user privacy under the Digital Personal Data Protection (DPDP) Act 2023. If any user or browser attempts to directly browse or download from /storage/secure_idv/, the guard intercepts and blocks it with HTTP 403 Forbidden.
Base64 Binary Encoder
Data Serialization
💡 Simple Analogy: Translating pictures into safe text.
Role in TerraByte: Encodes photo payloads into standard JSON text strings for transmission over HTTP, then reconstitutes them back into genuine .jpg files on the private storage disk.
SHA-256 Crypto Hashing
Integrity Seals
💡 Simple Analogy: A tamper-proof digital wax seal.
Role in TerraByte: Produces cryptographic fingerprints for verification certificates and digital E-Agreement deeds. Any modification immediately invalidates the seal.

3. Database & Storage Architecture Data Persistence

Where land parcel dossiers, compensation ledgers, officer audit trails, and biometric photos are permanently preserved.

Browser LocalStorage
Relational-Style Store
💡 Simple Analogy: A permanent digital filing cabinet.
Role in TerraByte: Houses the main application database (terrabyte_db_v2). Persists 100 georeferenced land parcels, acquisition proceedings, E-Agreements, user accounts, and immutable audit logs across computer restarts.
Browser SessionStorage
Auth Cache
💡 Simple Analogy: A temporary sticky note.
Role in TerraByte: Keeps track of the currently logged-in officer or citizen. Wipes automatically when the browser tab is closed for enhanced security.
Server Photo Vault
Encrypted File Vault
💡 Simple Analogy: A physical locked locker on disk.
Role in TerraByte: The private directory on the server disk (storage/secure_idv/) storing the physical .jpg verification photographs, accessible only to authorized internal server processes.
JSON Verification Ledger
Immutable Audit Log
💡 Simple Analogy: An official handwritten registrar book.
Role in TerraByte: An append-only historical logbook (verifications.json) storing verification reference IDs, masked PAN numbers, IST timestamps, and verification statuses.
